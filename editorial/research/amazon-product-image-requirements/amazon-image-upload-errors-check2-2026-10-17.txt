Image upload errors and display issues
On this page
Why your image isn't appearing
Fix image upload errors
Troubleshoot images with inventory files

If you received errors when uploading images, or your image isn't showing on your product detail page, review this page for the most common causes and fixes.

Why your image isn't appearing

If your image uploaded successfully but isn't showing on the product detail page, work through these steps:


Wait 24 hours. It can take up to 24 hours for an image to appear after upload.
Check compliance. Review the Product image guide to ensure your images meet all technical and content requirements. We check images for compliance after the initial upload scan.
Note: Images that fail to meet our product image requirements listed cannot be uploaded to our system or may be removed from search. Go to Image suppression to learn more.
Check your submission status. Go to Submission status to view the status of images you uploaded (Global/US and country-specific). ASINs displaying "Image upload completed" have been successfully processed. If there are issues, select the Content compliance issues report type for details.
Check for duplicates. If you upload the same set of images as a previous submission, we may detect it as a duplicate and your contribution will remain unchanged. When updating images, ensure they reflect actual changes (for example, different resolution or cropping) so the system recognizes the new submission.

Other considerations

Uploading an image doesn't guarantee it will be displayed on the product detail page. We select and arrange images from multiple selling partners to ensure each product has enough high-quality images for buyers. To maximize the chance of your images being displayed, ensure they comply with our product image requirements.
We may select images different from those you provided, including images that are different from those provided by sellers with a selling role (Brand Representative or Reseller) assigned in the brand.
If your product has multiple sizes or colors (a variation family), we automatically select images from one option to display across all size variations of that color or style.
If a listing is missing a main image, it will not display in the store. Always ensure your upload includes a main image (variant code: MAIN).

Fix image upload errors

If your image or images failed to upload in Upload images tool, find your error below:

Error	What happened	How to fix
Bad ASIN or variant	Your file could not be associated with an ASIN or variant.	Verify your file name follows the naming format: Product ID + variant code + extension (for example, B000123456.MAIN.jpg). Confirm the ASIN exists and you have an active offer for it.
Unsupported file suffix	Your file type is not accepted.	Convert your file to a supported format: JPEG (.jpg/.jpeg), TIFF (.tif/.tiff), PNG (.png), or non-animated GIF (.gif).
Image file was corrupted or in an unexpected format	The file is damaged or not in the correct format.	Confirm your file is not corrupt, is smaller than 10,000 pixels on the longest side, and is saved in a supported format (JPG, TIF, PNG, GIF) in RGB or CMYK color mode.
Image dimensions too small	The image's longest side is smaller than 500 pixels.	Upload an image that is at least 500 pixels on the longest side. For zoom functionality, use 1,000 pixels or larger. To check dimensions, view Properties for the file.
Authoritative image already exists	A preferred image already exists for this ASIN and variant.	Your image will not be accepted for this variant. If you believe the current image is incorrect, Upload a replacement image that meets all requirements and differs from the existing one.
Resubmission of previously accepted or rejected images	This exact file has already been submitted for this product.	Do not upload the same file multiple times. If your product still needs an image, it likely failed previously due to technical requirements. Make changes to the image (crop, adjust resolution, or re-export) so the system recognizes it as a new submission, then upload again.
Unknown internal error	An unknown problem occurred.	Try uploading again later. If the issue persists, verify your file meets all technical requirements.
Image with identical ASIN and variant submitted	A newer image was uploaded for this ASIN and variant while yours was still processing.	The newer image takes precedence. If you need to update the image, make a visible change (crop or increase resolution) so the system treats it as a new file, then re-upload.
Image and title do not match (error 100239)	The main image does not match the image file name.	Verify you uploaded the correct image and that the file name matches the intended ASIN.
Main image and product ID do not match (error 990003)	The submitted main image shows a different product than what's currently on the ASIN.	Upload a main image that shows the same product represented by the ASIN. If the product has materially changed, create a new listing instead.

Troubleshoot images with inventory files

An inventory file lets you specify a URL from which Amazon retrieves your product images. Errors in your file can prevent images from loading.

Note: You must use a direct URL. Pop-up or redirecting URLs will not be accepted and the upload will not process.
Symptom	What happened	How to fix
Image does not appear on Amazon	The URL does not point to the actual image file.	Verify the image URL is a direct link to the file and re-submit your product image feed.
Amazon rejects the image	The image at the URL is in an unsupported format.	Convert to JPG, TIFF, or GIF, update the URL in your file, and re-submit.

If your inventory file has errors:


Review and correct errors:
Check your processing report for errors. For more information, go to Review processing reports.
Correct the errors identified in the report. For more information, go to Error code explanations.
For invalid image URL errors specifically, go to Invalid URL format (error 15) .
Upload your corrected inventory file.
Repeat until your file processes without errors.
Allow up to 24 hours for images to appear.

Resolve zip file upload errors

Error	What happened	How to fix
Upload failed. Reduce the number of images and try again, or check for hidden files/folders in your zip.	Your zip file contains hidden system files.	




Enable hidden file visibility:

In Windows, open File Explorer and check "Hidden items" under the View menu.
In macOS, open Finder and press Shift + Command + period to show hidden files.
In Linux, open a terminal and use the ls -la command to view hidden files.
Extract the zip file.
Delete hidden files (files starting with "." or "__MACOSX" folders).
Re-zip the file and upload again.
Note: Each zip file is limited to 1,000 images and 1GB.

Correct country-specific image display issues

If your country-specific images are not displaying and global images show instead, the main image (variant code: MAIN) is not included in the country-specific upload. Without a main image, none of the country-specific images will be considered for display.

Re-upload the country-specific image set and include a main image.
