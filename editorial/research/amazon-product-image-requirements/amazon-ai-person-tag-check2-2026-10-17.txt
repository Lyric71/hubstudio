How to tag media that contains an AI-generated person
On this page
Tag images on macOS
Tag images on Windows
Tag media using command line tools
Verify the tag

If your image or video contains a AI-generated human, learn how to update the metadata.

To comply with jurisdictions that require disclosure of AI-generated people in product media, Amazon requires selling partners to tag applicable media before upload.

If your media contains an AI-generated person, you must add the contains-synthetic-performer keyword to the XMP dc:subject field. Specifically, the metadata must contain an rdf:li of contains-synthetic-performer inside the XMP dc:subject rdf:Bag.

Many XMP-capable tools are available depending on your operating system and workflow. The instructions below cover built-in tools for macOS and Windows, as well as a command line option for other systems.

Tag images on macOS

Use Preview to add the keyword:


Open the file in Preview.
Open the inspector with Cmd+I (or select Tools then Show Inspector).
Click the Keywords tab.
The Keywords pane will initially show "No Keywords.” (Fig. 1)

Fig. 1



Click the + button at the bottom of the pane.
Type "contains-synthetic-performer" and click Enter.
Result: The keyword appears in the list. (Fig. 2)

Fig.2

Tag images on Windows

Use File Explorer to add the keyword:


Right-click the file and select Properties.
Go to the Details tab.
In the Description section, locate the Tags field. (The Subject and Tags fields write to different metadata locations. Use only the Tags field)
Type "contains-synthetic-performer" into the Tags field.
Leave the Subject field unchanged.
Select OK.
Result: You’ll see the addition of the keyword. (Fig. 3)

Fig 3

Tag media using command line tools

Other cross-platform command line tools can add XMP tags for both images and videos across different system types (for example, Linux distributions).

The following example uses exiftool.

Tag a single file

To add the keyword, first check the current state, then write and verify:

exiftool -G1 javelinas.png | grep Subject
# (no output  -  Subject is empty)

exiftool -XMP-dc:Subject+=contains-synthetic-performer javelinas.png
# 1 image files updated

exiftool -G1 javelinas.png | grep Subject
# [XMP-dc] Subject: contains-synthetic-performer

Tag files in bulk

To tag multiple files at once, use the same command with broader file targets:

Tag all PNG images in the current folder:

exiftool -XMP-dc:Subject+=contains-synthetic-performer *.png
# 5 image files updated

Tag specific files individually:

exiftool -XMP-dc:Subject+=contains-synthetic-performer image1.png image2.jpg video.mp4 
# 3 image files updated 


Important details about the += operator:

The operator appends to the keywords bag without overwriting existing keywords.
Running the same command twice writes the keyword twice.
Duplicates do not break tagging, but they do bloat the XMP packet unnecessarily.

Verify the tag

After adding the keyword, verify that the contains-synthetic-performer value is present in the XMP dc:subject field. Use any tool that can show the explicit XMP dc:subject field.
