Uploading and managing files
Caution

You should only ever upload files to the Content > Files section of your Shopify admin when they're intended for public access on your store, such as product media, downloadable content, and other storefront images. Never upload any documents that contain confidential, personal, or sensitive information about you, your business, or your customers.

The Files section is where you can manage all files uploaded to your store, including images, videos, 3D models, and other file types, such as PDFs and CSV files. You can upload, manage, and delete files from the Files section in your Shopify admin.

The file picker is available in different areas of your Shopify admin, such as the following examples:

Adding media to a product.
Editing your theme.
Creating metafields.
Adding media in the rich text editor.

All files you upload through the file picker are added to the Files page of your Shopify admin.

File requirements

You can upload files to the Files page in your Shopify admin. Files must meet the following requirements:

Image file requirements
Attribute	Requirement
File size	Maximum of 20 MB (megabytes)
Resolution	Maximum of 25 MP (megapixels)
Aspect ratio	Between 100:1 and 1:100
File formats	JPEG, PNG, WEBP, HEIC, and GIF
File names	File names can contain letters, numbers, spaces, and symbols, but must not begin with a period .
Tip

Image file names can't end with the following words - pico, icon, thumb, testing, small, compact, medium, large, or grande. These endings can be misinterpreted as image transformation requests, such as resizing, by Shopify's CDN. If you upload an image with a name such as test_medium.png, then Shopify automatically appends a suffix to the filename to prevent conflicts.

Generic file requirements

Generic files can be any file other than HTML, and are intended for downloading by the customer.

Attribute	Requirement
File size	Maximum of 20 MB
File formats	Any file type except HTML
File names	File names can contain letters, numbers, spaces, and symbols, but must not begin with a period .

Note

Upload a file on the Files page

You can upload files to Shopify on the Files page. You can then use the uploaded files across your Shopify admin, including as brand images, product media, and metaobjects.

Steps:
Desktop

From your Shopify admin, go to Content > Files.

Click Upload files.

Select up to 200 files to upload, and then click Open.

Mobile
Note

As part of verifying your domain, you might be asked to upload files to the root folder of your site. If you're verifying your website with a third-party service, then use meta tags instead.

Search and filter the file list

You can filter the file list or search for a file from the Content > Files page of your Shopify admin or in the File picker.

You can filter your files in the following ways:

Search file attributes, including file names and types, using the search bar.
Filter by size using the File size range selector.
Filter by type using the File type menu.
Filter by file reference using the Used in menu.
Filter by alt text using the Alt text menu.

All filters display in-line in the search bar, so you get a full view of the criteria influencing your search results. You can also use is/is not and or/and logical operators to create more advanced views with specific filter criteria.

Tip

If you need to perform the same searches or filter by the same terms regularly, then you can save the filter view.

Learn more about searching, filtering, and sorting your list views in the Shopify admin.

Steps:

From your Shopify admin, go to Content > Files.

Optional: Click All to open the view menu, and then select the view that you want to filter.

Select an operator and value for your filter. The available values are different depending on the filter that you select.

Optional: Continue typing keywords to continue adding different filters and values to refine your search:

To include an additional filter with an and operator to your search, click  or add a space, and then start typing the name of the additional filter that you want to include.
To include an additional value with an or operator to a filter, add a comma, and then start typing the name of the additional value that you want to include.

Optional: Click the filter tags of any filter in the search bar to edit the filter.

Save filter view

If you need to perform the same searches or filter by the same terms regularly, then you can save the filters as views so that they're more easily accessible. Saved views are added to the views list at the left of the Files searchbar. You can click the selector to filter the files using the saved filter parameters.

Steps:
Desktop

From your Shopify admin, go to Content > Files.

Using the searchbar, apply the appropriate filters and search keywords.

Click Save.

In the Save view as dialog, enter a name for your saved filter view.

Click Save.

Use bulk action to delete multiple files

In any file view, you can select some or all of the files and delete them in bulk. You can switch between file views to continue selecting files, and apply filters or search using keywords to display only relevant files that you can also select.

Note

If you're on a desktop device, then you can click Show all selected to display only the files that you've currently selected.

Learn more about using bulk actions in your Shopify admin.

Steps:

From your Shopify admin, go to Content > Files.

Click a file view.

Select the items that you want to delete.

Click Delete files.

In the dialog, click Delete.

Change the sort order of the file list

By default, files are listed from newest to oldest based on the date that they were uploaded.

Note

If you change the sort order of your files in the Shopify admin on desktop, then the file list reverts to the default sort order after it's refreshed, such as when you navigate to a different view. You can save an alternative sort order using the Shopify mobile app.

You can change the sort order of your file list to any of the following options:

Sorting option	Value	Description
Date added	Sorted by date from Newest first or Oldest first.	This option displays files in the order that the products were created. By default, the file list is sorted by Date added: Newest first.
File name	Sorted alphabetically from A-Z or Z-A.	This option displays files in alphabetical order by file name.
Size	Sorted by file size from Smallest first or Largest first.	This option displays files in order of file size.
Steps:
Desktop

From your Shopify admin, go to Content > Files.

Optional: Click All to open the view menu, and then select the custom view that you want to review the sort order for.

Click the  icon to open the display option panel.

Click the  Sort by menu, and then select a sort criteria option, as well as a sort order.

Original media downloads

Shopify's Imagery service manages your images and videos to ensure the best possible format is displayed at the appropriate place in your online store.

You can download the original, unoptimized file to your device using the download button in the Preview and edit window.

Steps:
Desktop

From your Shopify admin, go to Content > Files.

Click the desired file, or use the filters to sort or locate a specific media file.

Click the download button. The original format saves to your device.

Editing files

You can preview and edit files by clicking the file's thumbnail from the Files page. Edits that you make on the Files page apply to all places the file is used in your store.

Review the following table to learn more about how to edit your files:

Action	Description
Rename a file	Update the name of your file by changing the URL Handle of your file. When you change your file's URL, the previous URL for that file no longer works.
Replace a file	Replace an existing file with a new file, and keep the same file name and URL handle. You can replace a file only with the same file format, such as replace a JPG file with another JPG file.
Add alt text	Add a brief description of the image or video for people with visual impairment or low-bandwidth connections.
Add a focal point to an image	Select the most important part of the image to help themes crop the image more intelligently.
Update a video cover image	Update the video cover image that acts as a preview image for your video.

You can also edit media files using the media editor and AI-powered media generation.

To make other types of edits, download the file, make the edits in an editing software of your choice, and then upload it again to the Files page.

Replace files

You can replace a file from the Files page. You can't replace files as a bulk action.

Note

When you replace a file, the file name stays the same, but the file's link changes.

Steps:

From your Shopify admin, go to Content > Files.

Click the Replace icon next to the file name.

Select the file that you want to upload.

Edit files without overwriting the existing file

In the file editor, it's possible to make destructive edits to an image, such as changing the background of an image. To make changes without overwriting an existing file, save the changes as new.

Steps:

From your Shopify admin, go to Content > Files.

Select a media file to open the file editor.

Make file edits.

From the Save dropdown menu, select Save as new.

Saving as new saves the new file to your store's file system and preserves the original image in its original state.

Best practices for file names

When you upload an image file, a unique identifier might be added to the filename. This can happen in the following situations:

A file with the same name already exists in your store. This includes files uploaded directly to product pages that might not appear in Content > Files.
The filename contains special characters or formatting that conflicts with Shopify's Content Delivery Network (CDN).

To prevent unique identifiers from being added to filenames, use the following file naming practices:

Ensure the filename is unique and doesn't match any existing files in your store.
Avoid using underscores immediately before image dimensions in the filename. For example, use product-image-5x4.jpeg instead of product_image_5x4.jpeg.
Use descriptive filenames that don't include special formatting.

If you need to change a filename after upload, then you can rename files from the Content > Files page by editing the URL Handle.

Generate image

You can generate images using AI directly in the unified file picker throughout the Shopify admin. This feature lets you create custom images for your products, content, and marketing materials without needing external tools.

When you generate an image, it's created temporarily and displayed in the file picker. To save the generated image to your store, you need to click Keep. If you don't explicitly save the image by clicking Keep, then the generated image will be discarded and won't be saved to your store.

Note

Generated images that aren't saved by clicking Keep are automatically discarded and don't count toward your storage limits.
