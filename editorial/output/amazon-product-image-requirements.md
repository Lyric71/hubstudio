# Amazon product image requirements for 2026, quoted from Seller Central

Pure white, 85 percent of the frame, 1,000 pixels for zoom. Those three come
straight from Amazon. Two things rarely reach the size guides: the places
where Amazon's own pages disagree, and a new line saying Amazon may edit the
files you send.

<!-- INTRODUCTION -->

## What are Amazon's product image requirements in 2026?

Amazon's product image requirements in 2026 center on the main image: pure
white (RGB 255, 255, 255), with the product filling 85 percent of the frame,
shown whole and only once. Files run 500 to 10,000 pixels on the longest side,
1,000 or more for zoom. hubStudio can build the files; Seller Central takes
the upload.

Reviewed October 17, 2026. Every rule below is quoted from Amazon's Seller
Central help for the US store, read that day in a logged-out browser. The help
pages carry no dates, so each row is dated by the read. Where two Amazon pages
disagree, both values are printed and each page is named.

| Requirement | Amazon's value | Amazon page |
|---|---|---|
| Main image background | Pure white, RGB 255, 255, 255 | Product image guide |
| Product in the frame | 85 percent of the image, whole, shown once | Product image guide |
| Pixels, longest side | 500 minimum, 10,000 maximum | Product image guide |
| Zoom | 1,000 pixels or more on the longest side | Product image guide |
| Files | JPEG (recommended), PNG, TIFF, non-animated GIF | Product image guide |
| Color | RGB; CMYK "Not preferred" | Technical image file requirements |
| Images per listing | One compliant main required; six more and a video recommended | Product image guide |

## What does Amazon require of the main image?

The main image carries the variant code MAIN. It's the picture shoppers see in
search, and 11 of Amazon's 14 suppression reasons apply to it alone. Without a
compliant one, Amazon may pull the listing from search until you fix it.

| Rule | What Amazon's page says | Source |
|---|---|---|
| Background | "a pure white background (RGB color values: 255, 255, 255)" | Product image guide |
| Fill | "Show the product as 85% of the image" | Product image guide |
| Whole product | Show all of it; "Do not cut off any part of the product" | Product image guide |
| Shown once | Front only, not front and back in one image | Product image guide |
| Quantity | One unit, plus accessories included with it | Product image guide |
| Realism | "a realistic, professional-quality image" at real scale, quantity and color | Product image guide |
| Placeholders | None, temporary ones included | Product image guide |
| Packaging | Only when it is an important feature, such as a carrying case | Product image guide |
| Props | None that aren't included and could confuse the customer | Product image guide |
| Mannequins | No part of one, clear, flesh-toned, framework or hanger | Product image guide |
| Text, logos, graphics, watermarks | A suppression reason on any main image | Image suppression |

> Amazon's main image must have "a pure white background (RGB color values:
> 255, 255, 255)" and should "Show the product as 85% of the image," whole,
> once and as one unit. Read from Amazon's own help article.
> Source: Amazon Seller Central, Product image guide, US store, page undated,
> read October 17, 2026.
> https://sellercentral.amazon.com/help/hub/reference/external/G1881

How is the 85 percent measured? The guide doesn't say. Two other Amazon pages
come close. The clothing page counts "85% of the total image area," for
clothing. The error codes page gives an example instead: a product filling
only 100 by 100 pixels of a 500 by 500 image is too small, because "at least
85% of a product image should be taken up with the product itself." For
everything else the method stays open. Pick one and hold it across the
catalog.

Lifestyle main images exist, but barely. Amazon's style guide page names six
product types that may use one: BED, BED_FRAME, MATTRESS, RUG, RUG_PAD and
SOFA. Everything else goes on white.

## What size, file format and file name does Amazon want?

| Setting | Amazon's value | Source |
|---|---|---|
| Longest side | 500 to 10,000 pixels; under 500 will not upload | Product image guide |
| Zoom | "Images with 1,000+ pixels on the longest side enable the zoom function" | Product image guide |
| Upscaling | "Do not artificially enlarge small images" | Product image guide |
| Formats | JPEG, TIFF, PNG, non-animated GIF; JPEG recommended | Product image guide, Upload images |
| Refused | EPS, BMP, PDF, and app files such as PSD | Technical image file requirements |
| Color | RGB; CMYK uploads but convert it; grayscale only for gray or silver metal | Technical image file requirements |
| Compression | Minimal or none; JPEG at the highest quality; remove layers | Technical image file requirements |
| File name, bulk | Product ID + variant code + extension: B000123456.MAIN.jpg | Product image guide, Upload images |
| Zip upload | Up to 1,000 images and 1 GB per zip | Upload images |

> Images must be 500 to 10,000 pixels on the longest side, and "Images with
> 1,000+ pixels on the longest side enable the zoom function." Read from
> Amazon's own help article.
> Source: Amazon Seller Central, Product image guide, US store, page undated,
> read October 17, 2026.
> https://sellercentral.amazon.com/help/hub/reference/external/G1881

The file name has three parts separated by periods. Spaces, dashes or extra
characters stop the upload. The ID can be the ASIN, UPC, ISBN, EAN, GTIN or
JAN. One trap: a file named with an ID and no variant code, B000123456.jpg,
uploads as the main image. The guide marks the naming rule optional, and the
Upload images page offers flexible naming as well: any file name, assigned to
products after upload.

Amazon contradicts itself in two places, and both matter at upload. Its
Product image error codes page says a file must be "at least 500 pixels on the
shortest side" and lists .tif, .tiff, .jpg, .jpeg and .gif, with no PNG. The
Product image guide, the Upload images page and the upload errors page all say
longest side and all accept PNG. That's three pages against one. A file at
least 500 pixels on both sides, saved as JPEG, clears every version.

The fill figure has a history too. Amazon's 2018 Quick Start Style Guide,
written by its Australian entity and still linked from the US style guides
page, asks for the product to "occupy at least 80 percent of the image area."
Build to 85. It passes both.

Size guides often print a 2,000-pixel recommendation, a 1,600-pixel zoom line
or a 10 MB file cap. None of those numbers appears on the Amazon image help
pages read for this guide. Amazon's line is 1,000 pixels for zoom, and it sets
no megabyte limit there.

## What can Amazon's additional images show?

More than the main image, with a few limits that follow every slot. Amazon
names each slot by a variant code, and the code says what belongs in it.

| Variant code | What Amazon says it is for |
|---|---|
| PT01 to PT99 | Additional angles, product in use, screenshots, accessories, product details |
| TOPP, BOTT, LEFT, RGHT, FRNT, BACK, SIDE | Other angles and sides of the product |
| SWCH | The swatch, usually a color sample; MAIN stands in when there is none |
| PS01 to PS06 | Warning and safety information, shown under Safety and Product Resources |
| INGR, EEGL, DTLS | Ingredients, the energy guide, multiples packed together |
| IN01 to IN99 | Interior shots, usually sample pages of books |

Lifestyle scenes belong in the PT slots, as "product in use." What every image
still can't carry, main or not: anything that misrepresents the product or
doesn't match its title; nudity or sexually suggestive images; customer
reviews, five-star graphics, claims such as free shipping, or seller
information; Amazon's logos, trademarks or badges, "Best seller" and "Amazon's
Choice" included.

Text is narrower than its reputation. The guide's line reads "No text or
pricing details (swatch image only)," so the text ban sits on the swatch, and
claims are banned everywhere. Selling in several countries? Text on a
country-specific image must be in that country's official language or in
English.

On AI, Amazon's rule is about people, not products: an image showing
photorealistic people generated entirely by AI must carry the keyword
contains-synthetic-performer in its XMP dc:subject field before upload.

## Which categories have their own Amazon image rules?

| Category | What changes | Amazon page |
|---|---|---|
| Adult clothing | Main on a standing model; not sitting, kneeling, leaning or lying down | Product image guide, Image guidelines for clothing |
| Clothing mains | Frontal view; aspect ratio "close to 3:4"; 85 percent of the total image area; no mannequin, hanger, folded product or selfie | Image guidelines for clothing |
| Clothing, all images | 1,000 pixels or more for zoom; children's wear under 1,000 pixels prohibited; up to eight alternate images per SKU | Image guidelines for clothing |
| Children's undergarments, leotards, swimwear | Photographed lying flat, never on a model | Product image guide |
| Clothing accessories and multipacks | Flat, without a model | Product image guide |
| Footwear | A single shoe, facing left, at a 45-degree angle | Product image guide |
| Multipacks | Main shows the total quantity delivered, in its packaging | Multipack imaging standards |
| Beds, mattresses, rugs, rug pads, sofas | A lifestyle main image is allowed | Product page style guides |
| Gray or silver metal products | Grayscale accepted | Technical image file requirements |

> Amazon's clothing page asks for a main image with a "Minimum aspect ratio is
> close to 3:4 (width/height) and 85% of the total image area occupied," shot
> on a model on pure white. Read from Amazon's own help article.
> Source: Amazon Seller Central, Image guidelines for clothing, US store, page
> undated, read October 17, 2026.
> https://sellercentral.amazon.com/help/hub/reference/external/G200498950

Multipacks flip the packaging rule. The general guide says no packaging on the
main image unless it matters; the multipack page says the main image "must
show the product in the packaging," with the full count the customer gets.
The title has to state that count too, so the picture and the title agree.

## Why did Amazon reject or suppress my product image?

Amazon's Image suppression page lists 14 reasons, and its fix never changes:
submit a compliant image. So the last column is ours. It's how we'd rebuild
the file in production, not Amazon's text.

| Reason, as Amazon names it | What Amazon says is wrong | Images | How to rebuild the file |
|---|---|---|---|
| Text, logo, graphics, or watermarks | Any of them on the main image | Main | Re-export from a clean master with no overlays |
| Non-white background | Background not pure white, RGB 255 255 255 | Main | Set the background to 255, 255, 255 and check the corners |
| Image missing | Main image missing or incorrect | Main | Upload a new MAIN; replace rather than delete |
| Additional items | Items not permitted for this product type | Main | Remove anything that doesn't ship with the product |
| Cropped product | Part of the product cut off | Main | Reframe with a margin on every side |
| Product not outside of packaging | Product in packaging, or brand or swing tags | Main | Shoot it out of the box, tags removed |
| Propping | Props inside, hiding or surrounding the product | Main | Hide supports or retouch them out |
| Blurriness or pixelation | Image blurred or pixelated | Any | Re-shoot or re-render; never upscale a small file |
| Product too small | Product too small in the frame | Any | Crop to about 85 percent fill |
| Prurience | Image is prurient | Any | Replace the image |
| Multiple product images | One product shown more than once | Main, apparel | One view only |
| Human model | Model used for a non-clothing product | Main, softlines except adult apparel | Shoot it off-model |
| Mannequin or hanger | Mannequin or hanger shown | Main, apparel or accessories | Model for adult apparel; flat for accessories |
| Model in non-standing position | Model not standing | Main, apparel | Use a standing frame |

Products removed from search show on the Fix tab in Manage Products. Files
that failed show under Submission status, report type Content compliance
issues. Then allow up to 24 hours for a replacement main image to appear.

Not every failure waits for review. Some happen at upload. Amazon's upload errors page names
two worth knowing before a reshoot. Error 990003 means the new main image
shows a different product from the one on the ASIN. "Resubmission of
previously accepted or rejected images" means the same file went in twice:
change it (crop, resolution, a fresh export) and Amazon reads it as new.

One sentence on the Product image guide is new this autumn. It wasn't there
when we read the page on September 14.

> "We may also modify images that you submit to meet the product image
> requirements or enhance the customer experience." The sentence appears on
> the October 17 read, in English and in the page's Chinese version, and not
> on the September 14 read of the same address.
> Source: Amazon Seller Central, Product image guide, US store, two dated
> captures of the same page compared, September 14 and October 17, 2026.
> https://sellercentral.amazon.com/help/hub/reference/external/G1881

The suppression page gives the example: Amazon may remove a watermark itself.
Don't count on it. The same page lists a watermark on the main image as a
reason to suppress the listing.

## How do you make Amazon-ready product images in hubStudio?

Start from a photo of the real product. Amazon asks for real scale, quantity
and color, so the honest route is to edit your own picture, not to invent the
product from a prompt.

In the Image studio, Edit an image takes your photo and an instruction, such
as a pure white background or a stray object removed. Add the E-commerce
packshot skill from the Catalog, and Improve with AI rewrites your prompt with it.
On the ChatGPT Image engines, pick an Opaque background and a resolution up to
4K (3840 pixels), which clears Amazon's 1,000-pixel zoom line with room to
crop. Transparent, which only the 2.5 engines offer, is no use for a main
image: it has to be white.

Then open the result in the Image editor, which is free. Crop to Square 1:1 or
draw your own frame, leaving about 85 percent fill. Save as JPG or PNG at the
size you choose. Skip WebP here: it isn't on Amazon's list. The editor works
on pictures up to 4,096 pixels on the long side.

The upload is yours. hubStudio doesn't connect to Seller Central; files go in
through Upload images or Image Manager.

step, and the product photo to lifestyle image how-to covers the PT slots.

## FAQ

### What are Amazon's main image requirements?

A pure white background, RGB 255, 255, 255. The product fills 85 percent of
the frame and appears in full, a single unit shown once, with only the
accessories that ship with it. No text, logos, watermarks, props, mannequins or placeholders.
Packaging only when it's a real feature, multipacks aside. Adult clothing goes
on a standing model; shoes go single, facing left, at 45 degrees.

### What size should Amazon product images be?

Between 500 and 10,000 pixels on the longest side, and 1,000 or more if you
want zoom, which Amazon recommends. Amazon sets no aspect ratio in its Product
image guide, though its clothing page asks for close to 3:4 on a clothing
main image. One Amazon page says 500 on the shortest side, so keep both sides
at 500 or more.

### Does the Amazon main image have to be on white?

Yes, pure white, RGB 255, 255, 255, which is hex #FFFFFF. A background that
isn't pure white is a listed suppression reason. Six product types are the
exception: beds, bed frames, mattresses, rugs, rug pads and sofas may use a
lifestyle main image, with no text or extra logos. Additional images can show
the product in use.

### Why was my Amazon image rejected or suppressed?

Amazon lists 14 suppression reasons: text or logos on the main image, a
background that isn't pure white, a cropped product, packaging or tags, props,
blur, a product too small in the frame and extra items among them. Check the
Fix tab in Manage Products and the Content compliance issues report, then
upload a compliant replacement with the MAIN code.

### Can I add text or logos to Amazon product images?

Not on the main image: text, logos, graphics and watermarks are a suppression
reason. On additional images the guide bans text only on the swatch, but
claims such as free shipping, review stars, seller details and Amazon's own
logos and badges are banned on every image. Text on a country-specific image
must be in that country's language or English.

### Can I use AI-generated images on Amazon?

None of Amazon's image help pages read for this guide bans AI. They ask for a
realistic, professional-quality image that shows the real product at its real
scale, quantity and color. The one AI rule is about people: photorealistic people
generated entirely by AI must be tagged contains-synthetic-performer in the
file's XMP dc:subject field before upload.
